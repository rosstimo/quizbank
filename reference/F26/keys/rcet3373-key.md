## Software Delays

<a id="key-pic-delays-001"></a>
### `pic.delays.001`

[Back to this question](../rcet3373.md#q-pic-delays-001)

> **Type:** Numeric · **Difficulty:** Medium · **Points:** 3 · **Tags:** `f26-w3`, `decfsz`

#### Question

A loop is `DECFSZ count,1` followed by `GOTO Loop`, with count initially N. Using 1 cycle for a normal DECFSZ, 2 cycles when it skips, and 2 cycles for GOTO, how many loop-body cycles occur for N=4? Do not include setup instructions.

_Numeric response in cycles._

#### Key

**Answer:** 11 cycles

**Why:** Three normal iterations cost 3 cycles each, and the final skip iteration costs 2: 3*3+2=11 cycles, equivalent to 3N-1.

#### Question

Why can the exact instruction-cycle timing of an embedded C loop usually not be determined from the C source alone?

- A. C has no loops
