#### Question

In the demonstrated computed-GOTO table, what does the input index ultimately select?

- A. A `RETLW` entry whose literal becomes the returned value in W
- B. The number of hardware stack levels
- C. The bank containing the current GPR
- D. The oscillator frequency

#### Key

**Answer:** A. A `RETLW` entry whose literal becomes the returned value in W

**Why:** The index changes the low Program Counter through `ADDWF PCL`, selecting one `RETLW` entry. That `RETLW` returns its literal in W.

Match each item with its role in the computed-GOTO lesson.

- PCL: ____________________
- PCLATH: ____________________
- RETLW: ____________________

#### Key

**Answer:** PCL → Readable/writable low byte of the Program Counter; PCLATH → Holding register that supplies upper PC bits during specific PC loads; RETLW → Returns from the table call while placing a literal in W

#### Question

A 16-entry computed-GOTO table is automatically safe from the 256-word low-PCL rollover hazard because it contains fewer than 256 entries.

- True
- False

#### Key

**Answer:** False

**Why:** Table length and linked placement are different. A short table placed near `0xXXFF` can cross the low-PCL rollover boundary.

#### Question

In PIC Assembler source such as `goto $-1`, what does `$` represent?

- A. The assembler location counter at assembly/link time
- B. A runtime read of the complete Program Counter
- C. The value currently stored in W
- D. The top value on the hardware return stack

#### Key

**Answer:** A. The assembler location counter at assembly/link time

**Why:** `$` is assembler location-counter shorthand. The assembler resolves the destination and emits a normal branch instruction; it is not runtime PC arithmetic.

#### Question

Why did the lesson keep `current_count` separate from the working `out_count` countdown register?

- A. The delay loop destructively counts `out_count` to zero, so a separate persistent copy preserves the selected delay for the next half-cycle.
- B. Only `current_count` can be stored in GPR memory.
- C. `out_count` is automatically cleared by `RETLW`.
- D. The hardware stack requires one register named `current_count`.

#### Key

**Answer:** A. The delay loop destructively counts `out_count` to zero, so a separate persistent copy preserves the selected delay for the next half-cycle.

**Why:** Persistent selected state and destructive working state have different roles. Reusing one register would lose the selected delay after the countdown completes.

#### Question

Which statement correctly distinguishes the two Program Counter boundary concerns discussed in class?

- A. Computed-GOTO tables must consider 256-word low-PCL rollover, while `CALL`/`GOTO` page selection uses 2K-word pages.
- B. Both mechanisms use only the same 256-word boundary.
- C. Computed-GOTO tables use 2K pages but `CALL`/`GOTO` use 256-word pages.
- D. Neither mechanism depends on PCLATH or linked placement.

#### Key

**Answer:** A. Computed-GOTO tables must consider 256-word low-PCL rollover, while `CALL`/`GOTO` page selection uses 2K-word pages.

**Why:** The computed-GOTO hazard is low-byte PCL rollover at a 256-word boundary. `CALL`/`GOTO` target formation has a separate 2K-word page concern using PCLATH upper bits.

#### Question

A square-wave output uses a 21 us delay for each **half-cycle**. What is the nominal frequency in kHz?

_Numeric response in kHz._

#### Key

**Answer:** 23.8095238 ±0.01 kHz

**Why:** One period contains two half-cycles: `T = 2 * 21 us = 42 us`. Therefore `f = 1/42 us = 23.81 kHz`.

#### Question

A delay routine has an exact calculated core time, but the input-polling code between output edges follows different branch paths from one half-cycle to the next. What timing effect should you expect at the output?

- A. The edge-to-edge period can vary because the total executed path changes, producing jitter.
- B. No change; only instructions inside the named delay routine affect the scope measurement.
- C. Only the amplitude changes; the timing remains exact.
- D. The PIC automatically inserts NOPs to equalize branch paths.

#### Key

**Answer:** A. The edge-to-edge period can vary because the total executed path changes, producing jitter.

**Why:** The oscilloscope measures every executed instruction between edges. Variable branch paths outside the named delay routine change the total path length, so the waveform can show jitter rather than one fixed offset.

### `pic.software-timing.w03.004`

[Back to this question](../rcet3373-w03-lookup-timing.md#q-pic-software-timing-w03-004)

> **Type:** Multiple choice · **Difficulty:** Hard · **Points:** 2 · **Tags:** `f26-w3`, `timing`, `frequency-resolution`, `reasoning`

#### Question

Why does a constant 20 us increase in half-cycle delay **not** produce a constant change in output frequency?

- A. Frequency is reciprocal to period, so equal time steps produce large frequency changes at short periods and smaller frequency changes at long periods.
- B. The oscillator changes frequency whenever the delay count changes.
- C. `RETLW` literals are logarithmically encoded.
- D. The prescaler changes automatically at low frequencies.

#### Key

**Answer:** A. Frequency is reciprocal to period, so equal time steps produce large frequency changes at short periods and smaller frequency changes at long periods.

**Why:** For a square wave, `f = 1/(2 t_half)`. Because the relationship is reciprocal, a fixed time increment maps to nonuniform frequency increments.
