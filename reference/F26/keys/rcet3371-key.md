## Bitwise Operations

#### Question

Given `value = 0xB6`, what decimal value results from `(value >> 4) & 0x07`?

_Numeric response._

#### Key

**Answer:** 3

**Why:** 0xB6 = 10110110. Shifting right four gives 00001011; masking with 00000111 leaves 00000011 = 3.

Which responsibilities are good candidates to move out of a large WinForms button-click handler? Select all that apply.
